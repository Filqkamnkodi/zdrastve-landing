# Health Priority Landing

Create a premium, modern landing page for a medical clinic in Bulgaria.

General Design Requirements

Language: Bulgarian

Style: Modern, clean, professional, trustworthy, healthcare-focused

Color palette: Blue shades (#0F4C81, #1E88E5, #64B5F6, white, light gray)

Design inspiration: Scandinavian minimalism + modern healthcare websites

Plenty of white space

Rounded corners

Soft shadows

High-quality medical imagery

Smooth scroll animations

Fully responsive (desktop, tablet, mobile)

Accessibility-focused typography and contrast

Premium and trustworthy appearance
